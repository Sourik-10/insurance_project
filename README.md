🚀 **Built an End-to-End Machine Learning Project: Insurance Charge Predictor**

I'm excited to share my recent project, **Insurance Charge Predictor**, an end-to-end Machine Learning application that estimates annual US health insurance charges based on personal and health-related information.

The project focuses on building a complete ML workflow, from data preprocessing and feature engineering to model training and deployment.

**🔍 What I implemented:**

🔹 **Data Preparation & EDA:** Cleaned the Medical Cost Personal Dataset by handling duplicate records, normalizing categorical values, and exploring data patterns.

🔹 **Feature Engineering:** Created BMI categories, age bands, and a smoker-obesity interaction feature to capture meaningful relationships in the data.

🔹 **Model Development:** Trained and compared three regression algorithms:
- Linear Regression
- Random Forest
- XGBoost

🔹 **Model Evaluation:** Evaluated models using RMSE, MAE, and R², selecting the best-performing model based on RMSE.

🔹 **API Development:** Built a REST API using FastAPI with a `POST /predict` endpoint.

🔹 **Web Application:** Developed an interactive Streamlit interface that automatically calculates BMI from height and weight and displays predicted insurance charges.

**🛠 Tech Stack:**

Python | Pandas | NumPy | Scikit-learn | XGBoost | FastAPI | Streamlit

**💡 Key Takeaway:**

This project helped me understand the importance of data preprocessing, domain-based feature engineering, model evaluation, and integrating a trained ML model into a usable application.
